# A10 · 恢复故障

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
派发前、派发后、结果写库前分别退出/断网；重启查询

1. 派发前（attempt prepared/dispatching 未发出）kill App → 重启：无 request.show 或 not_found → 任务失败/待核实，不重发
2. 派发后回执前断网：attempt unknown → 重连后 `task.reconcile` 用原 requestId 查询
3. 回执后写库前 kill：重启后 request.show 为 completed → needs_reconciliation，不重做
4. events 游标过期：观察 run.show/list 重同步，无 GUI 动作
5. 同一 intent 在恢复后重新提交：期望 blocked（额度 held）直到人工核实

## 通过条件
同 intent 无重复外发；unknown 保留核实路径。

## 证据
- 每一步至少一张前后截图，只记 sha256 到对应 case 的 `beforeEvidenceHash / afterEvidenceHash`；截图本身放本地证据目录（见 [README](../README.md)），不进仓库。
- 本步必填的记录字段：`operationId`、`taskId`、`attemptId`、`requestId`、`platformRunId`、`receiptId`、`businessFactId`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。
