# A02 · 干净安装

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
单独安装 App 与平台；先不启动平台再检查错误态

1. 干净 macOS 用户账户（无 `~/.config/2ndscreen`、无旧 WeChat assistant 残留）
2. 只安装 App，不启动平台，打开 App：期望连接页、步骤 discover 为 pending/failed、Driver 动作 0
3. `grep -r 2ndscreen` 包内容为空；`otool -L` 无旧 helper
4. 再安装并启动平台，重复检查进入 contract/pairing 步骤

## 通过条件
无 2ndscreen 包/环境依赖；未连平台不崩溃。
