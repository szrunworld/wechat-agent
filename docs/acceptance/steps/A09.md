# A09 · 停止接管

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
执行/等待审批/模型三阶段暂停，取消受理到静止逐帧记录

1. 执行中 `app.pause`：记录 cancelAcceptedAt、quiescenceConfirmedAt，期间 UI 为 stopping；静止后 act 计数不变
2. 等待审批时 `app.pause`：晚到的批准被拒绝（invalid_state），act=0
3. 模型草稿生成中 `app.pause`：晚到的草稿只落账本，不输入
4. 关闭 Hub/订阅页：控制 Run 不受影响
5. `window.requestHandback`：缺 CR03 时显示手动指引

## 通过条件
静止前显示 stopping，确认后 act 新增数为 0。

## 证据
- 每一步至少一张前后截图，只记 sha256 到对应 case 的 `beforeEvidenceHash / afterEvidenceHash`；截图本身放本地证据目录（见 [README](../README.md)），不进仓库。
- 本步必填的记录字段：`cancelAcceptedAt`、`quiescenceConfirmedAt`、`unexpectedInputCount`、`platformRunId`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。
