# A04 · 只读基线

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
确认测试账号；截图与可见会话、好友申请清单比对

1. 在 W01 确认测试账号（`account.confirm`），记录 accountId/revision
2. 跑一次 read_requests，比对 `list_read` fact 的 rows 与人工截图：行数、状态、coverage 一致
3. 故意让列表超过一屏：coverage 必须是 partial，不得是 end_confirmed
4. 零行页面：coverage 记录为 current_viewport/unreadable 而不是"全部处理完"

## 通过条件
覆盖准确；不把可见部分当全量。

- 本步必填的记录字段：`testAccountAlias`、`coverage`、`beforeEvidenceHash`、`afterEvidenceHash`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。
