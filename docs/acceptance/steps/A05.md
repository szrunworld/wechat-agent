# A05 · 坐标输入 spike

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
测试窗口 1x/2x、深浅色、移动、前台弹层、中文、人工干预

1. 分别在 1x 与 2x 屏幕、深色与浅色主题下绑定微信窗口，做一次只读 observe → recognize，记录 applicability
2. 移动窗口后再 observe：旧 snapshotId 的 act 必须被平台拒绝（stale_observation）
3. 前台弹层（如系统对话框）存在时提交点击：期望 blocked(capability_missing/unexpected_dialog)，不做前台旁路
4. 输入中文/emoji 到搜索框并回读；中途人工敲一个键，期望写门关闭并保留现场
5. 换登录账号：期望旧审批失效
