# A03 · 配对权限

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
平台批准最小 scope；拒绝/撤销后重复外发；检查他人资源隔离

1. 在平台侧以 paired principal 配对（CR01）；未配对时提交外发任务，期望 blocked(pairing_missing)、act=0
2. 撤销配对后再提交，期望同样 blocked，且 UI 能解释来源（principal/role）
3. 用第二个 paired 主体查询本 App 的 Run/request/artifact：平台应拒绝（T04，platform_owned，只记录结果）

## 通过条件
缺权限为 0 输入；权限来源可解释。

## 证据
- 每一步至少一张前后截图，只记 sha256 到对应 case 的 `beforeEvidenceHash / afterEvidenceHash`；截图本身放本地证据目录（见 [README](../README.md)），不进仓库。
- 本步必填的记录字段：`authorizationEvidenceId`、`actualResult`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。

## 禁止
- 不对未授权真实联系人发送任何验收消息或申请。
- 不 exec `2ndscreen`、不 osascript、不模拟真实指针点击；缺能力就记 blocked。
- 不预写 passed。
