# A11 · 更新卸载

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
更新 App、保持平台版本；保留待核实；卸载仅自身内容

1. 留一条 needs_reconciliation 任务 → 升级 App：任务与 facts 仍在，schema_version 递增
2. 降级到旧版本：拒绝打开更高版本账本，不清空
3. 模拟磁盘满/账本只读：停止外发，诊断可导出
4. 卸载：只删 App 自身目录，平台与微信不动
5. 诊断导出：默认不含正文/截图/凭证

## 通过条件
不删平台/微信；不清零不明记录；降级拒绝。

## 证据
- 每一步至少一张前后截图，只记 sha256 到对应 case 的 `beforeEvidenceHash / afterEvidenceHash`；截图本身放本地证据目录（见 [README](../README.md)），不进仓库。
- 本步必填的记录字段：`versions`、`appCommit`、`actualResult`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。
