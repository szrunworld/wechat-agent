# A07 · 添加好友

方案 §13 验收步骤。只由协调者在授权测试账号上执行；lane 不碰真实微信。

## 执行与记录
使用授权测试目标；正文编辑、取消、再批准；错误 ID 与已好友分支

1. 依赖 CR02（通用前台 input route）；缺路由时记录 blocked(capability_missing) 并标 blocked，不做旁路
2. 编辑验证语 → 取消 → 再编辑 → 批准：发送的必须是最后批准的正文（OCR 回读一致）
3. 错误 ID：期望 not_found，不继续
4. 已好友：期望 no_op(already_friend)
5. 发送后无"等待验证/已发送"标识：期望 sent_unconfirmed

## 通过条件
只发送批准最终内容；成功判据有证据。

## 证据
- 每一步至少一张前后截图，只记 sha256 到对应 case 的 `beforeEvidenceHash / afterEvidenceHash`；截图本身放本地证据目录（见 [README](../README.md)），不进仓库。
- 本步必填的记录字段：`targetAlias`、`operationId`、`taskId`、`attemptId`、`requestId`、`receiptId`、`businessFactId`。
- 时间戳带时区偏移；`testedAt` 为本步完成时间。
